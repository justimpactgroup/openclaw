# Security policy

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/justimpactgroup/openclaw/security/advisories/new),
not in a public issue, pull request or discussion. Include the affected package and version, how to
reproduce it and the impact.

We fix issues in the latest release of each `@justimpactgroup/*` package and publish a GitHub
security advisory with the fix.

Vulnerabilities in OpenClaw or ClawHub belong to
[OpenClaw's security policy](https://github.com/openclaw/openclaw/blob/main/SECURITY.md). A model
using a tool, even through prompt injection, for what the tool's README says it does is not a
vulnerability; a tool that does more than documented, ignores its configuration or skips a promised
approval is.
